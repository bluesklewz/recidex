Foundation

A system for the moment before the recipe exists.

Recidex generates recipes. The interface holds a threshold: something is arriving, not yet resolved. Depth blur, unhurried transitions and a single warm ground carry that state. Everything else is stripped to monospace and space.

01   Ground
Brown is the room. It is never a component fill — only the space components sit in.
02   No borders
Nothing is outlined. Separation comes from surface value, blur and space — never a stroke.
03   Paper is content
Off-white appears only where a recipe does. It marks the artifact, not the chrome.
04   Slow
Transitions run 400–900ms on a soft ease. Nothing snaps. Nothing spins.

Neutral  ·  Paper, ink, tint

Paper is the recipe artifact and nothing else — cards, sheets, print. Ink is the only text color allowed on paper. Tint is the single muted text value on brown; there is no opacity-based text in this system.

Accent  ·  Orange and red
Orange  #C07000
Interaction. Filled tags and metadata chips, focus rings, selected states, section eyebrows. Carries ink text when filled, never paper. Not a primary action color — generate is a paper button.
Red  #C43D2E
Rare marker. Batch and ID numerals, the active dot in a stack, one point of emphasis per view. Not destructive, not error, not a fill larger than 24px. If red appears twice in a viewport, one use is wrong.

Light variant

Token table only

Roles flip; hues do not. Paper becomes the ground and the brown ramp inverts, so ink carries body copy. Accents are unchanged — orange keeps ink text, red keeps its scarcity rule.

The liminal layer
