Foundation

A system for the moment before the recipe exists.

Recidex generates recipes. The interface holds a threshold: something is arriving, not yet resolved. Depth blur, unhurried transitions and a single warm ground carry that state. Everything else is stripped to monospace and space.

01 — Ground

Brown is the room. It is never a component fill — only the space components sit in.

02 — No borders

Nothing is outlined. Separation comes from surface value, blur and space — never a stroke.

03 — Paper is content

Off-white appears only where a recipe does. It marks the artifact, not the chrome.

04 — Slow

Transitions run 400–900ms on a soft ease. Nothing snaps. Nothing spins.

Neutral — Paper, ink, tint

Paper is the recipe artifact and nothing else — cards, sheets, print. Ink is the only text color allowed on paper. Tint is the single muted text value on brown; there is no opacity-based text in this system.

Accent — Orange and red

Orange  #C07000

Interaction. Filled tags and metadata chips, focus rings, selected states, section eyebrows. Carries ink text when filled, never paper. Not a primary-action color — generate is a paper button.

Red  #C43D2E

Rare marker. Batch and ID numerals, the active dot in a stack, one point of emphasis per view. Not destructive, not error, not a fill larger than 24px. If red appears twice in a viewport, one use is wrong.

Depth & motion

The liminal layer

Depth stack

Adjacent items sit behind the focused one, offset and progressively blurred: blur 4px at 50% opacity, then 10px at 30%. Maximum two layers back. Depth replaces pagination — the stack shows where you are.

Rules

Non-negotiable
R1

No borders. No outlines, no 1px strokes. Separation is surface value, blur, or space. Buttons and tags carry a 5px radius; every other surface is square. The graph's internal bracket rules are the one exception — structural recipe content, drawn in paper-edge on paper.

R2

Paper only where a recipe lives. If a surface is off-white and is not an artifact, it is wrong.

R3

One red per viewport. It marks identity or position, never state or danger.

R4

One primary button per view, and it is paper. Orange is interaction feedback, not a call to action.

R5

Text is never set with opacity. Use paper, tint or ink — the three defined text values.

R6

No spinners, no progress bars, no percentages. Waiting is expressed as streaming mono and breathing glow.

R7

Every gap comes from the spacing scale via flex or grid gap. No arbitrary margins.

R8

Layouts are off-center. Content sits in a column offset from the page, with the long edge left open.
